ENTRY 001 / EVALUATION

FILED 26 OCT 2026

PUBLIC · v0.1.0

oathgate

THE RULER
HYPOTHESIS

An ML evaluation is only useful if its method is fixed before the result is known.

METHOD

Freeze the methodology into a hash with oathgate predict. Run the eval, then use oathgate check.

RESULT

Exit 0 means the ruler holds; 1 means it moved; 2 means it cannot be checked. v0.1.0 has zero runtime dependencies and 55 tests on Python 3.11–3.13. The repo checks itself in CI with its own lock.

STATUS / NEXT

Public on GitHub and PyPI. v0.2.0 is planned with MLflow integration and LLM-judge definitions inside the hash.

REPOSITORY ↗PYPI ↗
HASH / PENDING ↗

The real ruler hash has not been supplied. In oathgate, the hash freezes the evaluation method before the run.

ENTRY 002 / AGENT MEMORY

FILED 26 OCT 2026

DATA DEPOSITED

memgate

THE GATE
HYPOTHESIS

Untrusted text should not write to an agent's long-term memory without a check.

METHOD

Use a deterministic local gate with provenance tagging and an action-time guard. No LLM runs inside the gate.

RESULT

A public pilot used three local ~24–31B models: Qwen, Gemma, and Mistral. The dataset is deposited on Zenodo.

STATUS

Public code and pilot data.

REPOSITORY ↗PILOT ↗DOI 10.5281/zenodo.23665517 ↗

No public ruler hash was supplied for this entry. The gate checks memory writes and preserves their provenance; this stamp is a placeholder.
