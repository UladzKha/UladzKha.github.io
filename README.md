# Lab notebook of Uladzimir Khadakouski

A static personal site about verifiable AI. GitHub Pages serves the HTML, CSS, JavaScript, and local Open Graph image directly. There is no package install or build step; `.nojekyll` disables Jekyll processing.

## Preview locally

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000`. The night shift toggle stores the chosen theme in local storage. Print styles produce a paper version.
